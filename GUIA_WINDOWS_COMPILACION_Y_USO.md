# Windows — guía consolidada

Desde la revisión documental del **2026-10-07**, las instrucciones de Windows
se mantienen en la [Guía de compilación, uso y diagnóstico](GUIA_INICIO_Y_PRUEBAS.md).
Incluye ejemplos PowerShell, configuración, preparación de PNG, reanudación,
DevTools y solución de problemas, junto a sus equivalentes en Fedora.

Este enlace se conserva para quienes utilizaban la ruta anterior. La evidencia
histórica de ejecuciones Windows está en [verificación](docs/verificacion.md);
la [bitácora de reorganización](docs/fases/fase_00_entorno.md#2026-10-07--consolidación-documental)
explica el cambio de ubicación.
